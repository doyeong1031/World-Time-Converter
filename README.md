# World-Time-Converter

A simple Java terminal application that allows users to compare and convert dates and times across multiple cities.

## The Problem

I grew up in South Korea and graduated from high school in Vietnam. My friends now live in different countries, including the United States, Australia, and Hong Kong. Calculating time differences whenever I want to contact them or make plans can be inconvenient and confusing.

## Project Goal

To make it easier to compare current times and convert specific dates and times between different locations.

## MVP Features

A program allows users to compare their current local time with the current time in selected countries. Users will be able to enter a specific date and time in a selected country and see the corresponding date and time in their own location. Also, they can enter a specific date and time in their own location and convert it to the date and time in another country. The program will also allow users to add and select multiple countries.

## Tech Stack

- Programming Language: Java
- Libraries: java.time, java.util
- External Tools: JDK, Terminal
- Data Storage: ArrayList, HashMap
- External APIs: None
